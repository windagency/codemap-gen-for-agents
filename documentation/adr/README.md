| [0038](0038-never-fragment-a-directory-across-modules.md)           | A single directory's production files are never split across Modules                                                                                                  |
| [0039](0039-execution-flow-module-ordering.md)                      | Modules are ordered by execution flow (dependency order), not by id                                                                                                   |
| [0040](0040-directory-reconciliation-skips-ties-and-rechecks-size.md) | Directory reconciliation skips ties and re-checks community size afterward                                                                                          |
| [0041](0041-package-name-is-a-fourth-naming-tier.md)                | A Module's owning Package name is a fourth naming tier                                                                                                                |
| [0042](0042-earlier-tier-names-are-reserved-against-later-collisions.md) | An earlier naming tier's unique name is reserved against a later collision                                                                                        |
| [0043](0043-force-view-scoped-to-file-and-external-nodes.md)        | Force-directed view is scoped to File and External nodes, not Symbol                                                                                                  |
| [0044](0044-exclude-globs-match-under-hidden-directories.md)        | Exclude globs match underneath a hidden ancestor directory too                                                                                                        |

| [0046](0046-interpolated-names-are-capped.md)                       | An interpolated composite name is capped, falling back past it when exceeded                                                                                          |
| [0047](0047-python-test-directory-and-conftest-convention.md)       | Python test files are also recognized by a test/tests/ directory and conftest.py                                                                                      |
| [0048](0048-config-files-are-excluded-from-clustering.md)           | Known build-tooling config files are excluded from clustering entirely                                                                                                |
| [0049](0049-never-merge-packages-across-modules.md)                 | A Module's files never span more than one Package                                                                                                                     |
| [0050](0050-overflowing-modules-skip-ambiguous-package-names.md)    | An overflowing Module's Package-name fallback is skipped when the Package owns other Modules                                                                          |

| [0052](0052-numbered-names-for-same-directory-collisions.md)        | Modules that collide at every tier are numbered against each other, not just ordinal                                                                                  |
| [0053](0053-force-directory-ties-between-substantial-groups.md)     | A directory tie between substantial groups is resolved, not skipped                                                                                                   |
| [0054](0054-deepname-filler-for-dishonest-package-fallback.md)      | The Package-name fallback's restriction applies regardless of why interpolation failed, and its filler is the real directory, not an ordinal                          |
| [0055](0055-package-root-distinguishes-ancestor-from-peer.md)       | The Package-name fallback requires being the Package's root, not just its only claimant                                                                               |
